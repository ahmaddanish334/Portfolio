# Data files

Place the 14 Formula 1 CSV files in this folder before running the load script.

Expected files:

- circuits.csv
- constructor_results.csv
- constructor_standings.csv
- constructors.csv
- driver_standings.csv
- drivers.csv
- lap_times.csv
- pit_stops.csv
- qualifying.csv
- races.csv
- results.csv
- seasons.csv
- sprint_results.csv
- status.csv

The raw CSV files are not stored in this repository.
